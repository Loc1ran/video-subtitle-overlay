# Video Subtitle Studio — Frontend

Interactive timeline and visual subtitle overlay editor built with React, Vite, and Tailwind CSS.

## Getting Started

### Development

```bash
bun install
bun run dev
```

### Build for Production

Building compiles optimized assets directly into the backend's static directory (`../app/static`):

```bash
bun run build
# or using the Windows batch script in the root directory:
# build_frontend.bat
```

## Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + OKLCH color design system
- **Components**: Radix UI primitives, Lucide icons
- **State Management**: TanStack Router & TanStack Query
